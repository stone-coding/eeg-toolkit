    API reference¶

    Configuration and logging¶

    eegkit.config ¶

    Pipeline configuration, loaded from YAML and validated with pydantic.

    load_config(path=None, **overrides) ¶

    Load and validate a YAML config (defaults when path is None).

    eegkit.logging ¶

    Structured (key=value or JSON) logging built on the standard library.

    StructuredFormatter ¶

    Bases: Formatter

    Render records as ts level logger event key=value ... or as one JSON object.

    configure_logging(level='INFO', as_json=False) ¶

    Install a single structured stderr handler on the eegkit logger.

    get_logger(name) ¶

    Return a child of the eegkit logger; pass context via extra={...}.

    Core analysis¶

    eegkit.io ¶

    Loading EEGBCI motor-imagery recordings with standardized channel names and montage.

    download_subjects(subjects, runs, data_dir) ¶

    Download (or find cached) EDF files; return {(subject, run): path}.

    standardize_raw(raw) ¶

    Clean EEGBCI channel names (Fc5. -> FC5) and apply the standard_1005 montage.

    Works in place and returns raw for chaining.

    load_run(subject, run, data_dir) ¶

    Load one EEGBCI run into memory with standardized names and montage.

    read_edf(path) ¶

    Read an EEGBCI-style EDF file from disk and standardize it.

    load_subject(subject, runs, data_dir) ¶

    Load and concatenate several runs of one subject.

    eegkit.preprocess ¶

    Preprocessing: filtering, bad-channel detection, re-referencing. All functions copy.

    filter_raw(raw, l_freq=1.0, h_freq=40.0, notch_freqs=None) ¶

    Band-pass (+ optional notch) filter. Notches at/above Nyquist are skipped.

    detect_bad_channels(raw, flat_std_v=1e-07, noisy_z=4.0) ¶

    Flag flat channels (std below threshold) and high-variance channels.

    Noisy = robust z-score (median/MAD) of log10 variance across channels above noisy_z.

    mark_bad_channels(raw, bads) ¶

    Return a copy with info['bads'] extended by bads.

    set_average_reference(raw) ¶

    Return a copy re-referenced to the average of good EEG channels.

    preprocess(raw, cfg=None) ¶

    Filter -> detect/mark bads -> average reference -> (optionally) interpolate bads.

    eegkit.epochs ¶

    Event extraction, epoching and amplitude-based epoch rejection.

    extract_events(raw) ¶

    Return (events, event_id) for left (T1) / right (T2) imagery cues.

    make_epochs(raw, tmin=-1.5, tmax=4.5, baseline=(-1.5, 0.0)) ¶

    Epoch EEG channels around the cues (no rejection; see :func:reject_epochs).

    reject_epochs(epochs, reject_uv=300.0, channels=None) ¶

    Drop epochs whose peak-to-peak amplitude exceeds reject_uv (µV).

    The criterion is evaluated on channels (default: all good EEG channels); channels missing from the data are ignored.

    eegkit.analysis.spectral ¶

    Power spectral density and band power.

    compute_psd_by_condition(epochs, fmin=2.0, fmax=40.0, tmin=0.5, tmax=None) ¶

    Mean PSD per condition over the task window [tmin, tmax].

    Returns ({condition: psd[n_ch, n_freq]}, freqs, ch_names).

    band_power(psd, freqs, band, relative=False) ¶

    Integrate PSD over band along the last axis (trapezoid rule).

    With relative=True the result is divided by the total power over freqs.

    band_power_table(epochs, bands, window=(0.5, 3.5)) ¶

    Long-format band power: columns condition, channel, band, power (V²).

    eegkit.analysis.erders ¶

    Event-related (de)synchronization: time-frequency power as percent change vs. baseline.

    ErdersResult dataclass ¶

    ERD/ERS in percent: negative = desynchronization (ERD), positive = ERS.

    compute_erders(epochs, channels=('C3', 'C4'), freqs=(6.0, 30.0), baseline=(-1.0, 0.0), crop=(-1.0, 4.0)) ¶

    Morlet time-frequency ERD/ERS per condition (Pfurtscheller: (P - R) / R * 100).

    Power is averaged over epochs first, then expressed relative to the mean power in the baseline window at each frequency. Edge effects are avoided by computing on the full epoch and cropping afterwards.

    band_erders(res, band, window=(0.5, 3.5)) ¶

    Mean ERD/ERS (%) per channel within a band and time window.

    eegkit.analysis.decoding ¶

    Left-vs-right imagery decoding: CSP + LDA with stratified cross-validation.

    decode_csp_lda(epochs, tmin=0.5, tmax=2.5, fmin=8.0, fmax=30.0, channels=None, n_components=4, n_splits=5, seed=42) ¶

    Cross-validated accuracy of CSP(log-variance) + LDA on a band/time window.

    Band-pass filtering is stateless across epochs, so it is applied once before CV; CSP and LDA are fitted inside each training fold only (no leakage).

    eegkit.viz ¶

    Figures: PSD comparison, ERD/ERS maps, band-power topomaps, decoding accuracy.

    plot_psd_comparison(psds, freqs, ch_names, channels=('C3', 'C4'), bands=None, title=None) ¶

    PSD (µV²/Hz, log axis) per condition at the given channels; bands shaded.

    plot_erders(results, vlim=80.0, title=None) ¶

    ERD/ERS maps: rows = conditions, columns = channels. Diverging scale centered on 0%.

    plot_band_topomaps(power, info, bands=None, title=None) ¶

    Topomaps of log band power per condition plus the right-vs-left contrast.

    power is long-format (condition, channel, band, power). The last column shows 10·log10(right/left) in dB, on a diverging scale centered on zero.

    plot_decoding_accuracy(df, title=None) ¶

    Bar chart of CV accuracy per subject (error bars = fold SD) with chance line.

    df needs columns subject, accuracy and optionally std.

    plot_traces(data, times, ch_names, scale_uv=100.0, markers=None, title=None) ¶

    Stacked EEG traces (data in volts, one row per channel) with event markers.

    plot_band_bars(powers, title=None, ymax_uv2=None) ¶

    Grouped bars of band power (µV²): one group per band, one bar per channel.

    Data management¶

    eegkit.bids ¶

    BIDS conversion (mne-bids) and reading of the converted dataset.

    bids_path(subject, run, root) ¶

    BIDSPath for one EEGBCI run (run label = the original EEGBCI run number).

    to_bids(subjects, runs, raw_dir, bids_root, overwrite=False, deidentify=True) ¶

    Convert downloaded EEGBCI EDFs to a BIDS dataset. Existing files are kept unless overwrite. With deidentify (default) dates are shifted and identifiers stripped before writing. Returns the BIDS paths of all runs.

    write_run_bids(raw, bp, deid_salt=None) ¶

    Write one recording (T0/T1/T2 or rest/left/right annotations) as BIDS EDF.

    If deid_salt is given the recording is de-identified first (see eegkit.deidentify).

    load_subject_bids(subject, runs, root) ¶

    Read and concatenate a subject's BIDS runs (preloaded).

    eegkit.pipeline ¶

    Batch pipeline: preprocess -> epoch -> analyze for many subjects, with caching.

    Layout under paths.output_dir::

    cache/sub-001/{epochs-epo.fif, stage1.json, bandpower.csv, psd.npz, erders.npz, ...}
subjects/sub-001/{status.json, qc.json, bandpower.csv, erders_summary.csv,
                  decoding.json, figures/*.png, report.md}
group/{decoding.csv, erders_summary.csv, summary.json, figures/*.png}

    Each stage stores a hash of everything it depends on (config sections + input files); a stage is skipped when the stored hash matches and its outputs exist.

    process_subject(cfg, subject, force=False) ¶

    Run (or reuse cached) preprocessing, epoching and analysis for one subject.

    aggregate(cfg, results) ¶

    Group-level tables, summary.json and figures from the cached per-subject results.

    run_batch(cfg, subjects=None, force=False) ¶

    Process all subjects (cache-aware) then write the group-level outputs.

    report_subject(cfg, subject) ¶

    (Re)build one subject's outputs from cache and write report.md; return its path.

    Data access and privacy¶

    eegkit.catalog ¶

    Metadata catalog (SQLite via SQLAlchemy): subjects, sessions, runs, channels, status.

    The catalog indexes a BIDS dataset (file keys relative to a :class:~eegkit.storage.Storage) and the outputs of the batch pipeline. It never stores names or birth dates; measurement times come from the (already de-identified) BIDS files.

    Catalog ¶

    Thin repository around the SQLAlchemy engine.

    index_bids(bids_root, storage, bids_prefix='bids') ¶

    Index every EEG run in a BIDS dataset. Idempotent; returns the number of runs seen.

    sync_status(output_dir) ¶

    Load subjects/*/status.json written by the pipeline; returns rows updated.

    publish_artifacts(cfg, storage) ¶

    Copy per-subject results into storage (BIDS derivatives) and register them.

    query_runs(subject=None, task=None, status=None, min_sampling_rate=None, max_sampling_rate=None, min_duration_s=None, min_channels=None, limit=100, offset=0) ¶

    Filter runs by metadata; returns (total_matches, page).

    eegkit.storage ¶

    Storage abstraction: a local-filesystem backend and an S3-compatible backend.

    The catalog and API address files by key (a POSIX-style relative path such as bids/sub-001/ses-01/eeg/....edf), so swapping local disk for an object store (S3, MinIO, a lab NAS gateway) only means constructing a different :class:Storage.

    StorageError ¶

    Bases: Exception

    Base class for storage failures.

    NotFoundError ¶

    Bases: StorageError, FileNotFoundError

    The requested key does not exist.

    InvalidKeyError ¶

    Bases: StorageError, ValueError

    The key is absolute, empty or tries to escape the storage root.

    Storage ¶

    Bases: ABC

    Minimal object-store interface.

    put_file(key, src) abstractmethod ¶

    Store the local file src under key (overwriting).

    open(key) abstractmethod ¶

    Open key for streaming reads (raises :class:NotFoundError).

    list(prefix='') abstractmethod ¶

    Yield keys beginning with prefix in sorted order.

    get_file(key, dest) ¶

    Download key to the local path dest.

    LocalStorage ¶

    Bases: Storage

    Files under a root directory. Keys can never resolve outside the root.

    S3Storage ¶

    Bases: Storage

    S3-compatible backend (AWS S3, MinIO, Ceph...) built on a boto3 client.

    Pass client to inject a preconfigured/fake client; otherwise one is created lazily (endpoint_url selects a non-AWS service such as MinIO).

    normalize_key(key) ¶

    Validate a key and return its normalized POSIX form (no leading slash, no ..).

    eegkit.api ¶

    FastAPI service over the catalog and storage (interactive docs at /docs).

    create_app(catalog, storage) ¶

    Build the application around a catalog and a storage backend.

    create_app_from_config(config_path=None) ¶

    Application factory for uvicorn --factory (config path via $EEGKIT_CONFIG).

    eegkit.deidentify ¶

    De-identification of recording metadata (a demonstration, not a HIPAA certification).

    Approach (see docs/privacy.md):

    • direct identifiers (names, birthday, record numbers, experimenter, device serial/site, free-text description) are removed or replaced by a keyed pseudonym;
    • measurement dates are shifted by a per-subject offset derived from an HMAC of the subject label with a secret salt, so intervals within a subject (and between its runs) are preserved but absolute dates cannot be recovered without the salt;
    • the birthday is dropped; :func:age_years gives an integer age at recording (capped at 89);
    • :func:scan_for_identifiers lets callers (and tests) prove that given terms no longer occur.

    get_salt() ¶

    Secret salt from $EEGKIT_DEID_SALT (a demo salt, with a warning, if unset).

    date_offset_days(subject_label, salt) ¶

    Deterministic per-subject backwards shift in [MIN_SHIFT_DAYS, MAX_SHIFT_DAYS].

    pseudonym(subject_label, salt) ¶

    Stable keyed pseudonym (P-xxxxxxxx) that cannot be reversed without the salt.

    age_years(raw) ¶

    Age at recording in whole years (capped at 89), or None if unknown.

    Call this before :func:deidentify_raw (which drops the birthday) if the age is needed, e.g. for participants.tsv.

    deidentify_raw(raw, subject_label, salt=None) ¶

    Return a de-identified copy of raw (the input is not modified).

    scan_for_identifiers(raw, terms) ¶

    Locations where any of terms (case-insensitive) still appear in the metadata.

    Searches every field of raw.info (including nested dicts), the annotation reference time and annotation descriptions. An empty list means none of the terms were found.

    deidentify_metadata(meta, subject_label, salt=None) ¶

    De-identify a flat/nested metadata dict (e.g. a participants row or catalog record).

    Identifying keys are dropped, date-like values are shifted by the subject's offset, and the subject id is replaced by its pseudonym.

    Real time¶

    eegkit.realtime.device ¶

    Device interface: the contract any EEG amplifier driver (real or simulated) implements.

    DeviceError ¶

    Bases: Exception

    Base class for acquisition errors.

    DeviceDisconnectedError ¶

    Bases: DeviceError

    The device went away (cable pulled, Bluetooth lost, USB reset...).

    StreamEndedError ¶

    Bases: DeviceError

    A finite stream (e.g. a replayed file with loop=False) has been fully delivered.

    Chunk dataclass ¶

    A block of consecutive samples as delivered by the device.

    seq increases by one per chunk produced, so a gap between consecutive received chunks means chunks were lost. start_sample is the index of the first sample in the continuous stream; markers holds (stream_sample_index, label) events inside it.

    AcquisitionDevice ¶

    Bases: ABC

    Abstract EEG acquisition device.

    A hardware driver (BrainProducts, g.tec, OpenBCI, LSL...) subclasses this and implements the same five members; consumers such as :class:~eegkit.realtime.OnlineProcessor and the GUI depend only on this interface.

    start() abstractmethod ¶

    Begin streaming (from IDLE, STOPPED or DISCONNECTED).

    stop() abstractmethod ¶

    Stop streaming and release resources. Must be idempotent.

    read_chunk(timeout=0.0) abstractmethod ¶

    Next chunk, waiting up to timeout s (0 = don't wait); None if none arrived.

    Raises :class:DeviceDisconnectedError / :class:StreamEndedError once the already buffered chunks have been drained.

    send_marker(label) abstractmethod ¶

    Insert an event marker at the current stream position.

    eegkit.realtime.buffer ¶

    Thread-safe multichannel ring buffer with overflow accounting.

    RingBuffer ¶

    Fixed-capacity (n_channels, capacity) circular buffer.

    Two ways to read:

    • :meth:latest - the most recent n samples, non-consuming (for display/windowing);
    • :meth:read_new - samples not yet consumed, advancing a read cursor. If the writer laps the reader, the oldest unread samples are overwritten and counted in :attr:overflow_samples (the data is lost, never silently).

    __len__() ¶

    Number of valid samples currently held.

    append(data) ¶

    Append (n_channels, n) samples; older data is overwritten when full.

    latest(n) ¶

    The most recent n samples (fewer if not yet available), oldest first.

    read_new() ¶

    All unread samples (oldest first); advances the read cursor.

    eegkit.realtime.mock ¶

    MockAmplifier: replays pre-recorded EEG in chunks at the real sampling rate.

    MockAmplifier ¶

    Bases: AcquisitionDevice

    Simulated amplifier streaming data ((n_ch, n_samples), volts) in real time.

    • Timing: chunk k is released at t0 + k * chunk_dt (absolute deadlines), so scheduling jitter does not accumulate into drift. speed > 1 compresses time (handy in tests); 1.0 is real time.
    • Ring buffer: every delivered sample is also written to :attr:buffer (the device's recent history, e.g. for display) - independent of how fast consumers read chunks.
    • Markers: stimulus markers ((sample, label) pairs, repeated each loop) plus user markers from :meth:send_marker; each chunk carries the markers inside it.
    • Faults (for testing consumers): :meth:inject_drop, :meth:inject_disconnect, and a bounded chunk queue that discards the oldest chunk when the consumer is too slow - like a real device FIFO, the producer never blocks.

    chunk_dt property ¶

    Wall-clock seconds between chunks.

    from_raw(raw, **kwargs) classmethod ¶

    Stream the EEG channels of raw; left/right (or T1/T2) annotations become markers.

    inject_drop(chunk_indices) ¶

    Lose the chunks with these sequence numbers (never delivered or buffered).

    inject_disconnect(after_chunks) ¶

    Disconnect once after_chunks chunks have been produced in total.

    eegkit.realtime.online ¶

    Online sliding-window mu/beta band power from a device's chunk stream.

    PowerResult dataclass ¶

    Band power for one analysis window. powers[channel][band] is in V².

    OnlineProcessor ¶

    Sliding-window band power at selected channels.

    Chunks go through optional common-average re-referencing (needs the full channel set), channel selection and a ring buffer; every hop_s of new data a Hann-windowed periodogram of the last window_s is integrated over each band.

    Failure handling:

    • dropped/overflowed chunks - detected by a gap in Chunk.seq. The window is reset instead of bridged, so no spectrum is ever computed across a discontinuity; output resumes once a full window of contiguous data has refilled.
    • device disconnect / end of stream - :meth:run stops cleanly and records the cause in :attr:stats (status).

    process_chunk(chunk) ¶

    Feed one chunk; return the results (usually 0 or 1) it completed.

    run(device, on_result=None, read_timeout=0.1) ¶

    Blocking loop: read chunks until stopped, disconnected or the stream ends.

    start(device, on_result=None) ¶

    Run in a background thread.
